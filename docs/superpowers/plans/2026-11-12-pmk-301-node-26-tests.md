# PMK-301: pass the test suite under Node 26 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (inline, no subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `npm test` exits 0 under Node 22.22.0 and Node 26.4.0, with the delete test still proving that a failed cleanup is reported.

**Architecture:** Test-only change. Child `node` runs whose output is parsed get `--test-reporter=tap`, so the parse no longer depends on the Node version's default reporter. The delete test accepts the error code each Node version gives for the same read-only folder.

**Tech Stack:** Node.js built-in `node:test`, `node:assert/strict`, `child_process.spawnSync`.

**Spec:** `docs/superpowers/specs/2026-11-12-pmk-301-node-26-tests-design.md`
