# PMK-60 log-time Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/pmkit:issues:log-time` and let `issues log-time` accept readable durations.

**Architecture:** A pure parser in `scripts/lib/duration.mjs` feeds the existing CLI command. A new command file owns the flow (parse, dry run, confirm, write, total) and degrades to a comment when `time_tracking` is `absent`. `progress.md` step 8 hands off to it.

**Tech Stack:** Node ESM, `node:test`, Markdown command files.

**Spec:** `docs/superpowers/specs/2026-10-31-pmk-60-log-time-design.md`
