Done in https://github.com/fredsvanelli/pmkit/pull/176.

`alerts list` and `alerts scan` now read `yarn audit` (Yarn classic), `pnpm audit`, `pip-audit` (`requirements.txt`) and `cargo audit`, as well as `npm audit`. Every scanner gives one alert per package.

There is a new severity, `unknown`. pip-audit alerts are always `unknown`, because pip-audit reports none. cargo takes its severity from the CVSS 3 score, and is `unknown` without one. An `unknown` alert gets a `null` priority, so `/pmkit:issues:security-alerts` asks for one.

`--report <scanner>=<file>` reads a saved report instead of running the scanner, so the commands work offline. A pip-audit dependency that was not audited makes the result incomplete.
