## Plan

1. `deploys list --environment` (and `ci logs --branch`) with no value answers `INVALID_INPUT` before `gh` runs.
2. `ci logs --run` reads `gh run view <id> --json workflowName,url,conclusion,status`, so `workflowName` and `url` are filled. `run` gains `conclusion`, `status`, `failed`, `hasLog` and `logNote`.
3. `logNote` says when the run has not finished, did not fail, was a `startup_failure` (no job ran, no log), or failed with a blank log. The log call is skipped for the first three. Exit stays 0.
4. Tests (host and CLI), goldens, README, SKILL.md and CHANGELOG follow.
