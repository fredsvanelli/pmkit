Implemented `issues bulk` and `/pmkit:issues:bulk`. PR: https://github.com/fredsvanelli/pmkit/pull/105

- One change per call (`move`, `assign`, `priority`, `estimate`, `label-add`, `label-remove`, `milestone`, `release`, `sprint`, `parent`, `link`) for every issue a filter or a saved view returns, through the existing operations.
- The dry run is the full preview with a digest. The real run needs it as `--expect` and writes nothing when the set changed.
- Refuses with no filter, above `--max`, with unreadable issue files, with a cut read, and with a rejected issue. A write that fails midway stops and lists applied, failed and remaining.
- Linear: `milestone`, `release` and an epic as `parent` answer `NOT_SUPPORTED`.

`npm test` passes: 3478 tests, 0 failures.
