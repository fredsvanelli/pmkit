Plan for PMK-53, from docs/superpowers/plans/2026-10-31-pmk-53-link-repo-command.md.

1. A pure module, scripts/lib/git-remote.mjs, parses remote URLs (https, ssh, scp form, git://) and picks a remote: origin, the only remote, or "ambiguous" when there are several and no origin.
2. yaml-edit.mjs gets removeKey, so a git host of none drops git_host.repo.
3. The CLI command `link-repo [--git-host] [--repo] [--remote] [--team]` edits .pmkit/config.yaml with setScalar and removeKey, keeps comments and key order, validates the result, and writes only on a real run. An invalid config refuses the dry run and the write. Linear validates the team against the workspace and refuses a team that breaks the mappings. Local has no scope.
4. The command file /pmkit:link-repo explains the difference from /pmkit:setup and always asks once. Scenario, README, skill table and CHANGELOG follow.

Criterion 1 (writes scope and host after confirmation) is covered by tasks 3 and 4. Criterion 2 (infers the host from the remote) is covered by tasks 1 and 3.
