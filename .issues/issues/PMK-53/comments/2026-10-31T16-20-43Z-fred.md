Implemented in https://github.com/fredsvanelli/pmkit/pull/97.

Adds /pmkit:link-repo and `pmkit link-repo`. It writes the host, the repo and, on Linear, the team to .pmkit/config.yaml, keeping comments and key order. It infers the host from origin (HTTPS, SSH, ssh://), from the only remote, and infers nothing for no remote, an unreadable remote list, an unknown URL or several remotes without origin. A host other than GitHub gives none. A Linear team is checked against the workspace and refused when it breaks the mappings. An invalid config is never written over. The command file always asks once.

npm test: 3210 pass, 0 fail. Both acceptance criteria are checked.
