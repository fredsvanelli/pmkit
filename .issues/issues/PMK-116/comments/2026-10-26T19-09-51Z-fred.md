The `issues list` handler in `scripts/pmkit.mjs` adds a warning when `--sprint current` returns no issues and `currentCycle()` finds no active sprint. The warning goes to stderr, in both the human and the `--json` modes:

`warning: there is no active sprint, so --sprint current matches no issues; run pmkit cycle list`

Exit stays 0, stdout stays `{ "issues": [], "problems": [] }` with `--json`, and the contract does not change, so other adapters need nothing new. With an active sprint, or with `--sprint none` or a sprint id, the output does not change.
