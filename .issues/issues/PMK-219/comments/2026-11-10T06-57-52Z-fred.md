## Plan

Spec: `docs/superpowers/specs/2026-11-10-pmk-219-more-todos-design.md`. Plan: `docs/superpowers/plans/2026-11-10-pmk-219-more-todos.md`.

1. **More tags** (criterion 1): `HACK` and `XXX` count like `TODO` and `FIXME`, and `@todo` (any case, also `@fixme`, `@hack`, `@xxx`) counts as the JSDoc and PHPDoc tag. A repeated comment keeps the strongest tag: FIXME > XXX > HACK > TODO. The command creates a `bug` for FIXME and XXX, a `task` for TODO and HACK (PEP 350 treats XXX as FIXME and HACK as a workaround).
2. **Parser** (criterion 2): the `<script>` and `<style>` elements of html, vue, svelte, xml and svg are read with JavaScript and CSS syntax (C-like for scss, less, sass, stylus). A quote with no closing quote on its line is code, so it no longer hides the comment after it. A Python triple-quoted string that starts its line is a docstring and reads like a block comment.
3. **Quieter warning** (criterion 3): types with no comments by nature (`.txt`, `.jsonl`, `.csv`, `.lock`, `LICENSE`, images, fonts, archives...) go to `skipped.noComments` with no warning; `.json`/`.jsonc`/`.json5` are read with the C-like syntax and `.gitignore`, `.gitattributes`, `.dockerignore`, `.npmignore` with `#`; the warning lists at most 10 types.
4. Command file, README, SKILL.md and CHANGELOG follow. `todo-key` does not change, so existing issues still match. Owner and blame stay in PMK-238.
