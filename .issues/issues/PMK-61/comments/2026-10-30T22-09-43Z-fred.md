Plan for PMK-61.

1. Add `prDiff` and `localDiff` to the GitHub host, with a 120 second timeout on every `gh` and `git` call.
2. Add the read-only CLI command `pr diff [--branch b] [--base b] [--max-lines n]`. It returns the pull request diff, or the local diff against the default branch when the branch has no pull request, with `source`, `truncated` and `lines`.
3. Add `/pmkit:issues:review <id>`. It compares the diff with each acceptance criterion (covered, partly covered, not touched), lists the gaps, and offers to post the result as a comment after one confirmation.
4. Update the README, the CHANGELOG and the skill routing table.

Spec and plan are in `docs/superpowers/` on the branch.
