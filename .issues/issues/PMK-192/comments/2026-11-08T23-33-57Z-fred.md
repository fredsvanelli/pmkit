# PMK-192 plan: validate `git_host.default_branch`

Spec: `docs/superpowers/specs/2026-11-08-pmk-192-default-branch-validation-design.md`. Each task is test first.

1. **Shared validator** (`scripts/lib/config.mjs`, `scripts/config.test.mjs`). Test `validBranch` (accepts `main`, `release/1.0`, `développement`; refuses `main; curl x|sh`, `-x`, `a..b`, `a//b`, `a/.b`, `x.lock`, trailing `/`, spaces, `$(x)`) and `resolveDefaultBranch` (unset, valid, invalid). Add `validBranch` and `resolveDefaultBranch`, and make `validatePmkitConfig` report an invalid name.
2. **CLI readers** (`scripts/pmkit.mjs`, `scripts/cli-pr.test.mjs`, `scripts/adr.test.mjs`). `defaultBranch(ctx)` uses the resolver; `issues branch`, `pr open`, `pr diff` and `risks` print the `note:` for an invalid value and use `main`. `docs next-adr` and `link-repo` use the shared `validBranch`. Test the fallback and the note for each, and a non-ASCII name.
3. **`default-branch` command** (`scripts/pmkit.mjs`, `scripts/cli.test.mjs`, `scripts/golden-cases.mjs`). Reads only, no tracker, no host. Returns `{ branch, configured, valid, note }`. Test unset, valid, invalid and a non-ASCII name.
4. **`validate`** (`scripts/validate.test.mjs` or the nearest test). An invalid `default_branch` shows as a `config` problem.
5. **Command files** (`pause.md`, `progress.md`, `review.md`, `investigate-bug.md`, `work.md`). Take `<base>` from `default-branch --json`. A test over `commands/**/*.md` fails on a line that names `git_host.default_branch` next to a shell command, and checks the four files call `default-branch`. Update the golden and scenario files that quote those steps.
6. **Docs**. `CHANGELOG.md` line under `## Unreleased`, `README.md` command table, `skills/pmkit/SKILL.md` if it lists commands.
7. **Verify**. `npm test` in the foreground, exit code 0. Tick the three criteria with `issues update PMK-192 --check n` and commit `.issues/`.
