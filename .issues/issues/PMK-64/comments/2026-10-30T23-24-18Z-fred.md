Summary of PMK-64. PR: https://github.com/fredsvanelli/pmkit/pull/90

- Added `pmkit todos scan [--path prefix]`, a read-only command. It scans the files git lists (tracked plus untracked and not ignored), skips `node_modules`, `.issues/`, `.pmkit/`, binaries and files over 1 MiB, and groups repeated comments into one candidate.
- It drops candidates that an existing issue matches by `todo-key:` line, by `file:line`, or by comment text of 15 characters or more. Closed and archived issues count.
- Added `/pmkit:issues:todos`. It previews the full list after the dry runs, always asks once, and creates through `issues create` with the `todo-key:` line in each description, so a second run creates nothing for the same comments.
- `npm test`: 3060 tests, 0 failures.
