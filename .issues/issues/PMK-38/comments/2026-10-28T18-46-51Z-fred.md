PMK-38 is done on branch `pmk-38-map-linear-projects-to-epics`. PR: https://github.com/fredsvanelli/pmkit/pull/61

What changed:

- Linear projects are epics. The epic id is the project identifier when it has the key shape, and the slug otherwise.
- An issue joins an epic through `parent`. The project shows as the parent when the issue has no parent issue.
- Each epic carries its health and progress. `epic get` lists the milestones and documents of the project.
- Publishing a status update creates a project update.
- Milestones and documents are read-only. Their creates answer NOT_SUPPORTED.

Checks: `npm test` passes (2097 pass, 0 fail, 19 skipped). `validate` passes with no problems. A read-only live check against the sandbox workspace passed. Project writes are proven on the fake only, and PMK-39 covers a live write.
