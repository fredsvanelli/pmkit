PR #380 (https://github.com/fredsvanelli/pmkit/pull/380) adds `scripts/lib/jira/credential.mjs` and `scripts/lib/jira/client.mjs`: REST v3 and Agile 1.0 with JIRA_EMAIL + JIRA_API_TOKEN as Basic auth, anonymous Cloud check, `myself` session, paging over offset and token lists, GET-only retries, and every failure mapped to a pmkit code (AUTH, RATE_LIMITED, NOT_SUPPORTED, NOT_CONFIGURED, INVALID_INPUT, NOT_FOUND, CONFLICT, UPSTREAM). Tests use a fake fetch (`scripts/fake-jira-api.mjs`). Live checks were skipped (no credentials) and are tracked in PMK-364 (EPC-14).
