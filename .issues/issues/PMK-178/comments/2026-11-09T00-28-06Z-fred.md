## Summary

PR: https://github.com/fredsvanelli/pmkit/pull/129

With checks, reviews or threads refused, `pr blockers` now lists the rules that did not run in `policies.unevaluated` and says `not checked` instead of `all met`; a `BLOCKED` merge names them as a possible cause. `INSUFFICIENT_SCOPES` and SAML refusals mark the area `unchecked`. A change request no longer blocks with `reviewDecision: APPROVED` or a required count of 0. `npm test` passes (exit code 0).
