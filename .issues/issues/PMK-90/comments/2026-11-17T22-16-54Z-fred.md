Plan for PMK-90, from the approved design `docs/specs/2026-11-17-pmk-90-github-discussions-design.md` (full plan in `docs/plans/2026-11-17-pmk-90-github-discussions.md`):

1. The stateful fake GitHub serves discussions (list, get, categories, the comment mutation) with a `seedDiscussion` helper.
2. `scripts/lib/github/discussions.mjs` reads discussions through GraphQL with the gh client and posts a comment, with `available: false` when Discussions are off.
3. Three GitHub-only CLI calls: `github discussions list`, `github discussions get <number>`, `github discussions comment <number> --body-file f`.
4. The command `/pmkit:github:discussions`: list, a six-part summary, an issue through `issues create` with one confirmation, then an offered `Tracked in #<issue>` comment. Docs in README, help, SKILL.md, CONTEXT.md and CHANGELOG.
5. A runbook, `docs/runbooks/discussions-github.md`, with its E2E test.
