PMK-25 is done in the branch. `pmkit render <board|roadmap|sprint>` writes a static view of the Local tracker as Markdown or HTML, to stdout, to `--out <file>`, or to `--save` under the git-ignored `.cache/render/`. The `/pmkit:local:render` command runs it from a plain request.

- Renderers live in `scripts/lib/render.mjs`, and the data gathering in `scripts/lib/render-data.mjs`, through existing tracker reads only.
- Output is deterministic (no clock), and a write never replaces a file that pmkit did not render.
- Tracker text is escaped in both formats. Members show by name, never by email.
- `npm test` passes (1181 of 1181). `validate` reports no problems.
