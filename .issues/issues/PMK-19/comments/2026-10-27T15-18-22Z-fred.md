Added the read-only `/pmkit:team:flow-metrics` command. It shows cycle time, lead time, throughput, aging and bug rate for a period, next to the same numbers for the previous period of the same length.

The command runs the existing PMK-18 `metrics` commands and adds no CLI change. It gives no verdict, only the direction and the difference, and it names the source as the event history. It writes nothing.
