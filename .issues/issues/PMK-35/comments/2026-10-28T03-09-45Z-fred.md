PMK-35 is done on this branch and open as PR #57: https://github.com/fredsvanelli/pmkit/pull/57

What it does:

- Maps Linear issues to pmkit issues in both directions, with acceptance criteria in a description section and types from `mappings.types`.
- Translates filters to Linear filters where Linear has an exact match. pmkit applies `blocked` and the shared sort.
- Pages with a 1000-issue cap and warns when the cap cuts the read.
- Handles relations: blocks, related, duplicate and parent, with inverses. Refuses loops.
- Treats `me` as the key owner and refuses `--as` with anyone else. Never retries mutations.

Checks: `npm test` passes and `validate` passes. The contract suite runs against a stateful fake. A read-only live check passed against the sandbox. Mutations were not run live, which PMK-39 covers.
