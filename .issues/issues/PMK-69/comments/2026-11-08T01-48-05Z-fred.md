## Review Focus

- No git host: PRs and deploys `null`, `ready` is `null` not `true`.
- gh logged out / missing: same as no host with `reason.nextStep`.
- 200 open PRs: `pullRequestsIncomplete: true`.
- Issue file that does not parse: `problems`, `complete: false`.
- Linear (no releases): falls to milestone or sprint with a note.
- Release with no issues: ready true only when read complete.
