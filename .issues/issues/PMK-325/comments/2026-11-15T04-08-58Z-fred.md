PR #302 (https://github.com/fredsvanelli/pmkit/pull/302) is open for review. The `docs adr-status` refusal now names the status glued to the first paragraph the reader sees when link reference definitions open the section as a block of their own. This works at the top level, in a quote or list item, and before a quote or item. It's done inside the PMK-322 walk (`statusSection`, `sectionEnd`'s `add`), and `statusLineOf` is unchanged.

Evidence:
- 14 new tests, dry run and real.
- `npm test` 5398 tests, 0 fail, exit 0.
- Develop x branch comparison on 150,000 random Status bodies (seed 325): 0 differences in refusal, writes and `adr-get`. All 6,384 name differences are explained.
- `adr-commonmark-diff` full run: 3,923,326 cases, 0 worse.

Follow-up candidates:
- Definitions in a quote or item of their own, which then closes.
- The first-line fallback when nothing reads as a status.
- `1. Accepted` never reads as a status.
