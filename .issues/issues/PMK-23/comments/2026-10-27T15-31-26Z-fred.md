Added the `release-notes` CLI command and the `/pmkit:report:release-notes` command.

- The command picks the latest released release, then the latest closed sprint, then the default period, and it says which basis it used and why.
- It accepts `--release`, `--sprint` (including `current`) or `--since` and `--until`, and it counts canceled and chore issues instead of listing them.
- `release issues --archived` lets notes cover archived done issues.
- The command saves the notes through `docs create` only after a dry run and a confirmation. Drafts go to a `-draft` path.

Tests: `npm test` passes 1471 of 1471, and `validate` reports no problems.
