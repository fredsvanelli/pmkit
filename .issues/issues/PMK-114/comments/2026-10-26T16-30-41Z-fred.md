PMK-114 is ready for review: https://github.com/fredsvanelli/pmkit/pull/18

`issues create --sprint current` and `issues update --sprint current` now store the active sprint id. With no active sprint both fail before any write, dry run included, with `INVALID_INPUT` "there is no active sprint" and next step `pmkit cycle list`, the same error `cycle add --to current` gives. `requireSprint` and `moveToCycle` share one helper, `requireActiveSprintId()`.

The usage strings show `[--sprint id|current|none]`. `commands/issues/create.md` and `update.md` describe the new error, and `create.md` now says `INVALID_INPUT` instead of `NOT_FOUND` for a missing parent, sprint or member.

Tests: 987 of 987 pass. Criterion 1: "createIssue with sprint current stores the active sprint id" and the CLI tests in `scripts/cli.test.mjs`. Criterion 2: "updateIssue with sprint current stores the active sprint id" and the same CLI tests. Both were also checked by hand on copies of the `team` and `basic` fixtures.
