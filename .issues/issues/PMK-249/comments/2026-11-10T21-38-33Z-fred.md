Plan for PMK-249

1. `createIssue` (Linear) resolves `--milestone` and checks it against the epic parent's project with the check `issues update` uses, then sends `projectMilestoneId`; the dry run shows `milestone`. (AC 1)
2. A milestone of another project is refused before any write with `milestone <id> is not in the project of the issue`. (AC 2)
3. A milestone with no epic parent is refused with "a milestone on a new Linear issue needs an epic parent" and next step "Add --parent <epic>". (AC 3)
4. Tests first in `writes.test.mjs` and `tracker.test.mjs`; CHANGELOG line; Local tracker untouched.
