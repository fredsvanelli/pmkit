The work is done and the PR is open: https://github.com/fredsvanelli/pmkit/pull/49

What changed:

- `scripts/lib/user-store.mjs` is the new user store. It lives outside the repository, in `PMKIT_HOME`, `XDG_CONFIG_HOME/pmkit` or `~/.config/pmkit`.
- It holds discovery cache entries that expire by TTL, and personal defaults.
- Folders are 0700 and files are 0600. Writes are atomic.
- It refuses to write inside a git work tree, and it refuses credential-shaped keys and values.
- The test helpers point `HOME` and `XDG_CONFIG_HOME` at temporary folders.
- A new test checks that no command writes a credential into the repository.

No CLI command was added.

Checks: `npm test` passed with 1529 tests and 0 failures. `pmkit validate` exited with 0 and reported no problems.
