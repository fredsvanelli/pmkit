## Delivery

PR: https://github.com/fredsvanelli/pmkit/pull/91

- Goals live in `.issues/goals/<ID>.md` (`title`, optional `target`, the description as the body). The ID is `GOAL-` and a code that follows `id_style`.
- Epics link to a goal through an optional `goal` key, set with `epic create --goal` or `epic goal <epic> <goal|none>`.
- `goal list`, `goal get`, `goal create` and `goal progress`. `goal progress` returns each epic's `deliverableProgress` and the sums, from the same counting function as `epic progress`.
- `strategic_goals` is native on Local. On Linear it is `absent`, and on a Business plan `detail.workspace` is `native` and the five operations are listed under `unsupported`.
- `validate`, the doctor and the export losses cover goals. The tracker format stays 2.
- `npm test`: 3089 tests, 0 failed.

Follow-up candidates: a `goal_prefix` config key; commands to update, close or delete a goal; a goal status or owner; serving Linear initiatives.
