Done in https://github.com/fredsvanelli/pmkit/pull/286. The write check now classifies each head write by shape (`writeShape`): one known-status line replaced in place with every other line byte for byte, or the whole section replaced by one line (compared with the base as before). A replaced line that is not a known status and a duplicated, reordered or moved line are worse. The known-status rule is a copy in the helper, not the head's. Full run `--base 3f24c7e6 --head 46e15ecd`: 2,690,320 cases, 92.5 s, 0 worse, exit 0. Mutations (date line replaced, kept line duplicated) exit 1. `npm test` exit 0 on Node 22. All three acceptance criteria are checked.
