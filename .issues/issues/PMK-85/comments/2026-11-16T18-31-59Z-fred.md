## Plan

Design: `docs/specs/2026-11-16-pmk-85-github-graphql-client-design.md` (approved 2026-11-16). Plan: `docs/plans/2026-11-16-pmk-85-github-graphql-client.md`.

1. Move `isMutation` and `operationName` from the Linear client to `scripts/lib/graphql.mjs`, so both clients share them. The Linear client re-exports them.
2. Add `createGithubClient` in `scripts/lib/github/client.mjs`. Each call runs `gh api [--hostname <host>] graphql --include --input -` and sends the query and variables on stdin, so the `gh` login is the credential and no token or value goes on argv (criterion 1).
3. Map each `gh` and GraphQL failure to a pmkit code with a next step, one test per row (criterion 2). Missing scopes and a fine-grained PAT refusal become `AUTH` (ADR 0007). On any host but github.com the next steps add `-h <host>`.
4. Retry queries after a timeout, no connection or HTTP 5xx. Send a mutation once. Track the rate limit and page through connections.
5. Tests run on an injected runner, so `npm test` starts no `gh`.
