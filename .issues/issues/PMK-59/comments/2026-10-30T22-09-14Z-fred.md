Plan for PMK-59.

1. Add the command file `commands/issues/estimate.md` (`/pmkit:issues:estimate <id>`). It uses existing CLI operations only: `capabilities`, `discover`, `issues get`, `issues list`, `issues update --estimate` and `issues comment`. No new operation, so Linear needs no `unsupported` entry.
2. Criterion 1: the command reads the issue and the code it touches, finds completed issues (`--category done`) with similar titles, and proposes a value from the project's estimate scale, with the evidence.
3. Criterion 2: the proposal and the dry-run before/after are shown together and the user confirms once. Then `issues update --estimate` runs for real.
4. Criterion 3: when the `estimation` capability is `absent`, the command posts the estimate and its basis with `issues comment` instead.
5. Tests: a scenario module and snapshot for the Local path, the command registration in `plugin.test.mjs`, and the command-file count.
6. Docs: README table, `skills/pmkit/SKILL.md` routing, CHANGELOG line.
