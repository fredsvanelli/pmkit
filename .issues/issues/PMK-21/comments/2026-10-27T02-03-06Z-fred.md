Added `pmkit risks`, a read-only command that prints six lists: blocked issues, stalled issues, stalled PRs, epics at risk, broken CI on the default branch, and open PRs with failing checks.
Added `/pmkit:team:risk-radar`, which runs the command and formats the report. It writes nothing and asks nothing.
Without a git host, or when `gh` fails, the report keeps the tracker lists and marks the host lists as not checked.
Tests: `npm test` passes 1146 of 1146, and `validate` reports no problems.
The plan commit names `commands/team/risk-radar.md` before `d7cfb2e` adds it, so the suite fails at `75ac189` and passes at `d7cfb2e`.
