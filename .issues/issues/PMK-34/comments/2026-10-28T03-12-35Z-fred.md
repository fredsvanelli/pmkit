Stage 6 is done. The work is in PR #58: https://github.com/fredsvanelli/pmkit/pull/58

What the PR does:

- Adds `mappings.types` to the schema, an object from each pmkit type to one Linear label.
- Adds a generic mappings module and a Linear one with `resolveMappings`, which returns `types` and `typeOf`.
- Makes `init --tracker linear` work out the proposal in its dry run and take answers through `--team`, `--status`, `--field` and `--type-label`. Setup shows one summary and writes once.
- Uses Linear's native estimate field only. An absent key means none.
- Stops reads and writes with NOT_CONFIGURED and `error.mappings` when a mapping stays broken after one discovery refresh. Setup turns every broken key into a question.
- Updates `commands/setup.md` for the tracker question, the batched questions and the declined summary.

Tests: `npm test` passes (1817 tests). `validate` passes.

The PR also shows the sync commit of PR #55 until that PR merges. PR #58 should merge before PR #57 (PMK-35).
